# Security Policy

Codex Explorer is a local tool that indexes Codex session files. Reports may involve sensitive local paths or session content, so avoid sharing private session data in public issues.

To report a vulnerability, use GitHub private vulnerability reporting for this repository:

https://github.com/Tobiadefami/codex-explorer/security/advisories/new

If private reporting is unavailable, open a minimal public issue that describes the impact without including secrets, private paths, or raw session contents.
